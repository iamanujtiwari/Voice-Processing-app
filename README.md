# 🎤 AI Voice Changer App

An advanced AI-powered voice changer built using Python and Streamlit.  
This application allows users to record audio, apply voice effects, and play/download the modified voice in real time.

---

## 🚀 Features

- 🎙️ Record voice directly from browser
- 🔊 Voice amplification
- 👩 Female voice effect
- ⚡ Real-time audio processing
- 🎵 Audio playback support
- 💾 Temporary audio saving
- 🌐 Streamlit web interface

---

## 🛠️ Technologies Used

- Python
- Streamlit
- NumPy
- SciPy
- SoundFile
- audio-recorder-streamlit

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/voice-processing-app.git
cd voice-processing-app
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run voicechanger.py
```

---

## 📄 requirements.txt

```txt
streamlit
audio-recorder-streamlit
soundfile
numpy
scipy
```
